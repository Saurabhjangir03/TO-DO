# TO-DO Backend API

A simple backend project for managing TO-DO tasks using Node.js, Express and MongoDB.

## 🚀 Features
- Create, update, delete TO-DO tasks
- Get all tasks
- RESTful API structure
- Clean folder structure (routes, controllers, modules)
- Environment variables support

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv
